# Zeno Store

Modern, mobile-first watch e-commerce platform.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- PostgreSQL + Prisma
- Auth.js
- Zod
- Cloudinary

## Planned modules
- Customer storefront
- User authentication and accounts
- Admin dashboard and role-based access
- Product and inventory management
- Cart and checkout
- Orders and status tracking
- Coupons (including NEW20)
- Product reviews and customer feedback
- Store settings

This repository is being built with a scalable architecture from the start.
